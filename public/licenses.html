한글 문서 형식 고지

HWP 보기 · 변환 도구는 한컴이 공개한 한글 문서 파일 형식 문서를 바탕으로 만든 오픈소스 rhwp로 문서를 열고, 배포용 문서의 복사·인쇄 제한 표시를 읽는 부분은 공개 문서를 참고해 집문서가 직접 만들었어요. 공개 문서의 이용 조건에 따라 아래 문구를 적어요.

  • 본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
  • 본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

출처: 한컴 「HWP 문서 파일 형식」 공개 페이지(store.hancom.com/etc/hwpDownload.do)의 사용권 및 저작권 안내, 「한글 문서 파일 형식 5.0」 revision 1.3 저작권 쪽. 한컴은 결과물의 정확성을 보증하지 않아요.

상표

한글·한컴·HWP·HWPX는 ㈜한컴(옛 ㈜한글과컴퓨터)의 상표예요. 집문서는 한컴과 제휴·후원·승인 관계가 없는 독립 도구예요. Microsoft Word는 Microsoft Corporation의 상표이고, 카카오톡은 ㈜카카오의 상표예요.

LGPL 라이브러리(heic-to) 안내

  • /vendor/heic-to-1.5.2-csp.mjs 는 npm 의 heic-to@1.5.2 배포본(dist/csp/heic-to.js)과 똑같은 파일이에요. 고치지 않았어요.
  • 원본 소스: heic-to (1.5.2 패키지) · libheif 1.22.2 · libde265 1.0.16
  • 브라우저가 HEIC 사진을 스스로 못 열 때만 따로 불러오는 독립 파일이라, 집문서 소스를 받아 이 파일을 직접 고친 빌드로 바꿔 끼울 수 있어요.

집문서가 고친 부분

배경 지우기 라이브러리 안의 ndarray 가 new Function 을 써서 이 사이트의 보안 정책(CSP)에 막혀요. 그 부분만 작은 대체 구현으로 바꿔 다시 묶었어요(2026-10-13). 바꾼 코드와 다시 만드는 방법은 소스 저장소의 dev/ 에 있어요.
