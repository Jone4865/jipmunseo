합치는 순서

고른 PDF는 목록에 쪽 수와 같이 보여요. 순서를 맞춘 뒤 합치기를 누르면 돼요.

1. PDF 고르기

여러 개 한꺼번에

한 번에 여러 개를 골라도 되고, 빠진 파일은 나중에 더 넣어도 돼요. 한 파일은 300MB까지예요.

2. 순서 맞추기

이름순 · 끌기

컴퓨터에서는 줄을 끌어서, 휴대폰에서는 위로·아래로 단추로 옮겨요. 이름순은 숫자를 숫자로 세서 정리해요.

3. 합쳐서 저장

이어서 하기

합친 PDF를 내려받거나, 결과 아래 '이 파일로 이어서'에서 용량 줄이기·신분증 가리기로 바로 넘겨요.

합치기 전에 알아 둘 것

  • 책갈피(목차)와 입력 칸은 합친 파일로 따라오지 않아요. 쪽 내용은 그대로예요.
  • 암호가 걸린 PDF는 넣을 수 없어요. 암호를 푼 뒤 다시 넣어 주세요.
  • 제출 용량이 정해져 있으면 합친 뒤 PDF 용량 줄이기로 맞춰요.

PDF가 아닌 서류

  • 한글 문서는 HWP 보기에서 PDF로 저장한 뒤 넣어요.
  • 사진·스캔 이미지는 이미지 → PDF에서 한 PDF로 묶어요.
  • 필요 없는 쪽을 빼거나 돌리려면 PDF 나누기나 회전 · 순서 바꾸기를 써요.

자주 묻는 것

몇 개까지 합칠 수 있나요?

개수는 정해 두지 않았어요. 다만 기기 메모리 안에서 합쳐서, 휴대폰에서 아주 큰 PDF를 여러 개 합치면 느리거나 멈출 수 있어요.

휴대폰에서 고른 순서가 뒤죽박죽이에요

휴대폰 파일 고르기는 누른 차례대로 파일을 넘겨줘요. 목록 위의 이름순을 누르면 파일 이름대로 정리돼요.

돈이 드나요?

아니요, 무료예요.
